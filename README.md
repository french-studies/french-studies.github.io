# Society for French Studies website

This repository contains the second iteration of the temporary SFS site, put together (in haste) to replace an older site that was heavily reliant on PHP and unpatchable. The content is very similar to the old one, but this version uses an out-of-the-box Jekyll theme (_Just the Docs_) that supports parent and child pages, in order to limit the amount of information that had to be displayed on a single page.

The site was put together by Edward Mills ([webmaster@sfs.ac.uk](mailto:webmaster@sfs.ac.uk)).
